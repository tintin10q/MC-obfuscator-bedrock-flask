Basic Obfuscation

This is a website that will obfuscate Minecraft bedrock function code. Obfuscation is protecting code by making it hard to read.

Replace names

The tool uses regex to replace all the names in your functions with random generated names from the character pool.
This includes the names of:

  • Function
  • Objectives
  • Tags
  • Entities
  • Fake players

The same names are replaced with the same obfuscated name in every file. So, if an objective in one file is called jump and it is replaced with OO00O then in every other function jump will be replaced OO00O. As function names are changed the function file names are also updated accordingly. The website knows how to deal with subfolders! This means that all your subfolders will be gone and replaced by one long list of obfuscated function names.

Remove readability

Every line that starts with a # is removed. Empty lines to separate code are also removed.


Customization options

Use a blacklist

If you do not want to replace some names for any reason then you can blacklist the names per type. Names should be seperated by new lines.

There is a partial match option. If this option is enabled than every name that has an item on the blacklist as powill be blacklisted as well. This can for instance be useful if you have loads of functions called main, but they are all in different subfolders. Then using partial match and just the world main all the functions with main in them are blacklisted.

There is also a whitelist mode. With this enabled the blacklist will act like a whitelist so it will only obfuscate the names on the list. This option is not provided for function names because it caused a lot of issues with the name updating of the function files.

Generate a list of changes

If the include json file with changes checkbox is checked a json file with all the changes is included with all the changes per category and all the settings used.

Character pools

You can choose from 4-character pool presets. This will be the characters that can be used to create new names.

Obfuscated name length

You can set the start length of the names that will be generated. If the website runs out of possible names to generate it will increase the length. Generally, it is not recommended to change this setting. Do not move the length higher than 16 if you obfuscate scoreboard objectives as these names can not be longer than 16.
